- 删除 `.data/travel-agent.db`（旅行规划阶段的 SQLite 数据库，131072 字节）。该文件未被 Git 跟踪，删除后不可从版本库恢复。

- 删除 `修改记录/` 下 18 份旅行规划阶段的修改记录，仅保留智能客服阶段的两份（`替换为Python智能客服并适配原模型接口.md`、`清理旧项目残留与重复配置.md`）。

### 2. 移除旅行项目的上游远端

- 执行 `git remote remove upstream`，移除指向 `https://github.com/yichunfu5-prog/travel-agent.git` 的远端，仅保留 `origin`。

### 3. 清理配置与文案中的旅行/高德残留

- `.gitignore`：移除 `vector_store/`、`.tmp/`、`.probe*/`、`.p1/`、`.p2/`、`.tools/` 六项旅行阶段目录，并将注释改为与本项目一致。
- `README.md`：删除"当前项目已替换原旅行规划代码"、"模型请求仍走原项目模型网关，未调用高德地图"、"当前工作目录保留 Git 历史、协作约定和历史修改记录；原代码不参与运行"三处表述，改为与当前项目一致的说明。
- `.env.example`：删除"可直接复用原 travel-agent 的 .env"表述，并注明 Redis 为可选且需自行安装。
- `python-impl/settings.py`：模块 docstring 由"复用根目录原旅行项目环境变量"改为"读取根目录 .env 中的模型配置"。

### 4. 清理未使用的依赖声明

- `python-impl/requirements.txt`：移除 `redis>=5.2.0`、`opentelemetry-instrumentation-fastapi>=0.50b0`、`httpx>=0.28.0`、`tiktoken>=0.8.0` 四项。

## 修改原因

用户要求检查项目文件夹，删除不属于本智能客服项目的内容，并要求改动纳入 Git 以便追溯。工作区此前同时存在"旅行规划"与"Python 智能客服"两个阶段的产物，容易在阅读代码和准备项目材料时造成混淆；依赖声明中也存在与实现不符的条目。
