# 简化旅行规划为单智能体并建立基础验证

## 修改内容与原因

- 移除酒店、景点、天气子 Agent，单个 TripPlanner 直接装配并去重高德地点、天气及路线工具，减少不必要的编排层。
- 调整 CLI 与 Streamlit 的初始化，保留现有公开调用方式与行程展示。
- 合并提示词，要求按实际工具参数调用、先查询坐标、未知远期天气不编造、费用估算明确说明。
- 流式输出保留空白增量，避免地名等文本被拼接破坏。
- 新增不含密钥的 .env.example，重写当前 README；旧架构文档保留为历史参考。
- 建立 15 条固定需求、真实执行基线脚本和三项自动回归测试。

## 验证结果

- 普通环境中模型及 MCP 依赖导入通过；确认旧环境报错来自受限运行环境，未修改系统配置。
- 三项本地回归测试通过：工具去重及重复构建、空工具报错、流式空格和工具进度。
- 相关 Python 文件语法检查通过。
- 旧版和新版真实长沙规划均完成并可解析，耗时分别为 97.23 秒与 107.73 秒。单次样本不支持性能提升结论。
- 新版天气查询完成，采集 2 次模型调用和 5162 tokens；完整对比与指标缺失说明见 docs/首轮架构验证.md。
- 新版真实流式天气查询完成，收到 14 个输出片段、合计 126 个字符。

## 未完成与限制

- 尚未运行全部 15 条评估，不将单次可解析视为业务质量通过。
- Streamlit 入口及语法已检查，未进行浏览器页面交互验收。
- 结构化业务校验、统一超时重试、数据库、多轮修改、FastAPI 和 RAG 留待后续实施。
