# 知识检索与事实检查

知识库采用中文双字词与英文词的BM25检索，先按用户、城市和资料过期日期过滤，再返回最多4个片段。无需额外Embedding服务。每份资料最多50000字符，700字符分块、100字符重叠；每用户最多50份。当前是适合小型资料集的词法RAG，不是向量或语义检索。

认证API：`POST /knowledge`导入、`PUT /knowledge/{id}`替换更新、`GET /knowledge`列出、`GET /knowledge/search?query=...&city=...`检索。页面侧栏可上传同格式JSON。本机CLI可执行`python knowledge_cli.py knowledge_samples/palace.json`，导入到local命名空间；登录用户使用认证API或页面导入，不能读取local或其他用户资料。

样例根据[故宫官方导览](https://www.dpm.org.cn/Visit.html)在2026-11-01查阅后摘要整理，包含淡季时段和票价、周一例外、预约提醒；不是实时抓取器。样例2026-11-08过期后不参与检索，必须重新查阅更新，不能只改日期假装已复核。来源URL只作为归属链接，服务端不会抓取用户传入的任意地址；禁止带凭据的来源URL。

检索片段作为参考资料传入规划。片段ID包含文档、位置和快照摘要，避免重排或更新后引用串号；模型引用使用`[资料ID]`。返回分别保存`knowledge_references`（检索候选）和`cited_sources`（正文实际引用），不能把检索命中当作模型已引用。未知引用拒绝保存。历史版本保留生成时的来源片段与摘要，不因更新知识库重写历史。

结构化facts可包含地点名称/别名、日期有效范围、开放/停止入馆/闭馆时间、明确闭馆日期、常规闭馆星期、成人票价与预约要求。规则检查发生在保存前：

- 明确时间重叠、交通预留不足、已知日期闭馆、超出开放或停止入馆时段、同口径票价不一致时，拒绝保存新版本并保留错误。
- 来源明确基础入场免费时，不允许直接填写收费门票；可选交通或展演必须说明口径，不能混入基础门票。无可核验活动也不算核验通过。
- 只有明确的成人单人口径`ticket_price_basis=adult_per_person`才比较成人大门票；儿童、团体、额外展馆和估算混合费用不冒充已核实。
- 常规周一闭馆可能有法定假日例外，标记待核实，不武断判定具体节假日一定闭馆。
- 预约凭证由用户确认，模型声称已预约不算证据。缺少、过期或相互冲突的资料，缺少时间或交通耗时，均明确待核实。

`fact_check`分为`conflicts`、`needs_review`及`consistent_with_sources`。最后一项仅表示已表达字段与给定资料一致，不证明资料真实性、实时价格、路线耗时来源、库存或预约成功。当前不自动从地图响应提取可信路段证据，也不自动覆盖全国景点资料；绝不能用绿灯替代真实出行前核查。

导入资料属于用户提供数据，不可自动认定为官方认证；即使链接指向官方网页，也需要核对摘要是否正确。检索上下文明确为非指令，但不宣称已彻底解决模型提示注入。

另提供岳麓书院与橘子洲的官方来源摘要样例，均于2026-11-01查阅、2026-11-08过期。导入时适用于当前用户，不自动共享给其他账号；出行前仍须检查临时公告。
